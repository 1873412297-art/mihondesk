## mihondesk 0.5.0

本次带来新版本提醒、全新的页面过渡动画，并修复了几类取消操作和错误被悄悄吞掉的问题。

- **新版本提醒**：启动一分钟后和之后每 24 小时检查一次新版本，发现后弹出系统通知，并在活动中心和「设置 → 关于」的更新卡片里提示，点击直接打开更新卡片。只提醒、不自动下载，同一版本只提醒一次，可在更新卡片上关闭自动检查。更新卡片会显示这一版的更新内容。
- **界面与动效**：切换页面、进出阅读器、打开书架详情侧栏、详情页加载完成时都有过渡动画，书架卡片悬停时轻微浮起；Windows 关闭了「显示动画」时一律跳过。各页面标题对齐到同一位置；书架标题与操作按钮合为一行，显示模式改为一组分段按钮；批量操作栏的「完成」按钮固定在右侧，窗口窄时也不用横向滚动。
- **稳定性**：取消操作不再被吞掉后继续执行，例如取消迁移不会再以空章节列表完成迁移、取消的自动同步检查不再照样同步；网页验证与 Cookie 等浏览器同步调用设置上限，浏览器卡住时扩展不会无限等待；本地漫画详情的章节操作失败不再导致异常；备份恢复、导入、Drive 登录与同步失败会写入日志；换一本漫画后不再沿用上一本的章节搜索与多选。
- **Android 伴侣应用（测试版）**：读取 Mihon 的自动备份，通过 Google Drive 与桌面端同步书架、分类和阅读进度，详见 [mobile-companion/README.md](https://github.com/1873412297-art/mihondesk/blob/main/mobile-companion/README.md)。

### 安装

- `mihondesk-0.5.0.exe`：推荐，下载后按向导安装
- `mihondesk-0.5.0.msi`：需要 MSI 安装方式时使用
- `mihondesk-0.5.0-windows-x64-portable.zip`：便携版，完整解压到可写目录后运行其中的 `mihondesk.exe`
- `mihondesk-0.5.0-macos-arm64.dmg`：macOS（Apple Silicon）版。未签名、未公证；首次打开请在 Finder 中右键选择“打开”
- 下载后请使用 `SHA256SUMS.txt` 校验文件完整性

安装版数据仍保存在 `%APPDATA%\MihonW`，升级不会丢失书架、图源、设置与登录数据。
