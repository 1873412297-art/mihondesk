# 桌面版工作总结与发布说明（2026-09-28，v0.2.22）

本文件总结 v0.2.22 的交付内容（对标 Android Mihon 的升级计划 Phase 0–3，详见 `docs/desktop-upgrade-plan.md`），作为发布说明与交接依据。

## 一、发布物

| 产物 | 说明 |
|---|---|
| `mihondesk-0.2.22.msi` | Windows 安装包（per-user，含开始菜单与快捷方式） |
| `mihondesk-0.2.22.exe` | Windows 安装器 |
| `mihondesk-0.2.22-windows-x64-portable.zip` | 便携版（解压即用，数据随包） |

发布包内容约定与 0.2.21 一致：不含任何图源扩展、用户配置、书架数据库、Cookie 或缓存；打包链 `verifyCleanDistribution` 与 `verifyRuntimeModules` 两道校验保持强制。

## 二、健壮性加固（Phase 0）

- **同步服务器安全边界**：请求体流式读取 + 16 MiB 上限（超限 413）；token 常量时间比较；deviceId 所有权绑定 + 游标单调递增与空洞拒绝（409）；同载荷重推幂等 204；游标过滤下推 SQL。
- **可诊断性**：新增滚动文件日志（`logs/mihon.log`，5MB×5），接入启动/同步/下载/扩展关键路径；全局未捕获异常处理器落日志；诊断包可导出真实日志。
- **存储**：书库数据库开启 WAL + busy_timeout；迁移快照自动修剪（保留最近 5 个）；
- 静默 catch 全部接日志；Tracker 冲刷失败指数退避；修复下载器取消竞态（`NoSuchElementException`）。

## 三、桌面交互基建（Phase 1）

- **真后退栈**：Esc / Alt+← / Backspace 在任意子页面后退；Upcoming 转正式路由；
- **全局快捷键**：Ctrl+1~8 切换主导航、Ctrl+F 聚焦搜索、F5/Ctrl+R 刷新、`?` 快捷键速查（输入框聚焦时自动避让）；
- **Snackbar + Undo**：信息反馈去模态化；删除历史、移出书库、取消下载、清除已完成均可撤销（物理删除章节与清空历史保留确认对话框）；
- **右键菜单**：书架卡片、章节行、图源行、历史条目、下载卡片全面支持；图标按钮与导航栏全量 Tooltip；
- 窗口标题随内容动态变化；最小窗口尺寸 960×640。

## 四、功能对齐 Android（Phase 2）

- **迁移**：自动匹配（标题规范化 + 相似度打分 + 置信度徽章）、批量「全部迁移」（限流、可取消、失败报告）、分类与跟踪绑定完整搬运（幂等）；
- **每漫画设置覆盖**：阅读模式/预载页数按漫画覆盖（存储兼容 Android `viewer_flags`/`memo_json`，零 schema 迁移）；
- **下载队列**：单项暂停/恢复、上下移排序（持久化）、右键菜单；
- **更新流**：日期分组 + 行内操作（已读/下载/阅读）；
- **书架展示选项**：未读/已下载角标开关、网格尺寸滑杆收进对话框；
- **阅读器**：预载页数 1–10 可调、Hiatus/Cancelled 等状态徽章补齐、翻页瞬时页码提示；
- **浏览/搜索**：全局搜索「仅固定图源」、图源语言过滤与隐藏（可撤销）、全局 NSFW 开关（默认关）；
- **备份**：导出/恢复六类内容可选（格式与 Mihon 完全兼容）；
- **首次运行引导**：语言/主题 → 扩展仓库 → 备份设置三步引导（可跳过、可重放）。

## 五、i18n 清扫（Phase 3）

- 39 处内联三语文本全部迁入字符串表，`RecoveryText.kt` 删除；用户可见硬编码英文清零；用户可见日期时间全部本地化（跟随界面语言）；`i18n/README.md` 补充新增语言指南。

## 六、验证与质量

- `:desktop-app:test` 957 个测试全绿（多轮强制重跑无游移失败）；`spotlessCheck` 通过；
- 本版修复过程中发现并修复：DB 驱动线程跳转死锁、偏好缓存跨实例不可见回归、Compose UI 测试负载饥饿（预算加固）、下载测试拆除竞态。
