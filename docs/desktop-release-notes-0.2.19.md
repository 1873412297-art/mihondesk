# 桌面版工作总结与发布说明（2026-09-23，v0.2.19）

本文件总结本轮桌面版（mihondesk）的修复与改进，作为 v0.2.19 发布说明与后续交接依据。

## 一、发布物

| 产物 | 说明 |
|---|---|
| `mihondesk-0.2.19.msi` | Windows 安装包（per-user，含开始菜单与快捷方式） |
| `mihondesk-0.2.19.exe` | Windows 安装器 |
| `mihondesk-0.2.19-windows-x64-portable.zip` | 便携版（解压即用，数据随包） |

**发布包内容约定（重要）**：安装包与便携包**不含任何图源扩展（`.mext` / `.apk`）与用户插件**，也不含用户配置、书架数据库、Cookie 或缓存。打包链上的 `verifyCleanDistribution` 与 `verifyRuntimeModules` 两道校验会在产物违反约定时直接让构建失败。应用内置的"本地图源"（Local source）是读取本地文件的代码功能，不属于第三方图源扩展。

## 二、本轮修复的生产缺陷（7 项）

| # | 缺陷 | 影响 | 根因 |
|---|---|---|---|
| 1 | Tracker 登录必失败 | Bangumi 等无法登录 | okhttp 默认 `User-Agent: okhttp/x` 被 Bangumi 的 Cloudflare 拦截（403）。修复：统一 UA 拦截器 |
| 2 | Tracker 写入报 415 | 搜索/收藏写入失败 | okhttp 5.x 的 `String.toRequestBody` 会自动追加 `; charset=utf-8`，严格服务端拒绝。修复：统一走字节数组请求体 |
| 3 | 跟踪"编辑"按钮无响应 | 无法手动改进度/评分 | 主对话框与编辑对话框同时组合导致弹层失效。修复：三对话框互斥组合 |
| 4 | 单本阅读永不同步 | 同人本读完不上报进度 | 非正章节号（-1.0）被进度守卫永久跳过。修复：映射为 1.0 后再比较 |
| 5 | 扩展仓库删不掉 / 添加报错 | 仓库管理不可用 | 存储原始字符串与规范化身份不匹配；单仓失败拖垮整体刷新。修复：身份规范化 + 懒迁移 + 逐仓容错 |
| 6 | 打开图源网页必崩 | WebView 完全不可用 | jpackage 模块清单缺 `jdk.httpserver`（另缺 `java.net.http`、`jdk.dynalink`），开发机具全模块故不可见。修复：补模块 + 新增产物模块校验防回归 |
| 7 | 封面大面积空白 | 书架/详情页无封面 | 一屏 60-100 个封面并发无节制请求打爆队列并超时，且 UI 把一次失败永久记住。修复：6 并发信号量 + 退避重试 + UI 不再锁死占位符 |

## 三、产品改进（3 项）

1. **网络代理统一管辖**：新增 `DesktopPolicyProxySelector`，图源请求、tracker 同步、扩展仓库索引、扩展包下载、封面加载全部遵循"设置 → 高级与诊断 → 网络代理"（系统代理 / 直连 / HTTP / SOCKS）。此前五处客户端各自走系统代理，Clash 类代理下会静默失败。
2. **缺失图源检测与引导安装**：导入备份后若书籍所属图源扩展未安装，详情页显示横幅、导入完成弹汇总对话框，可一键安装对应扩展（复用既有信任流程）。
3. **失效封面自动修复**：封面返回 404/410 时自动重取一次详情（每部仅一次，防循环）；书架顶栏提供"修复失效封面 (N)"批量入口。

## 四、UI 与体验

- **布局排版**：主导航图标补文字标签；设置页统一 880dp 限宽 + 12dp 卡片分区；进度记录页按"公网服务 / 自托管实例"分组并加服务徽章；书架顶栏操作分主次；详情页操作行重排、剥离描述里的原生 Markdown 符号。
- **阅读器光标**：错误页因手势区被禁用而无法恢复隐藏的光标，导致"重试"按钮点不到。修复：非就绪状态强制显示光标 + 鼠标移动上报不再受就绪门控。
- **错误提示可读化**：Cloudflare 拦截（1005/1015/1016/1020 等）翻译为含处置建议的本地化文案，替代裸 `HTTP error 403`。

## 五、验证与质量

- 本轮新增/维护的单测全绿：tracker 契约、扩展仓库（含等效 URL 互删、旧数据迁移）、代理选择器、`shouldRetryCoverFetch`、封面失败登记表、读者光标可见性、缺失图源解析器。
- 实机验证：Bangumi 与 AniList 生产矩阵全链通过（登录→搜索→绑定→进度写入→解绑）；扩展安装（AsmHentai）成功；图源浏览页封面恢复；WebView 验证窗口可正常打开。
- 打包链新增两道门禁：`verifyCleanDistribution`（禁止用户数据与扩展包进入产物）与 `verifyRuntimeModules`（禁止运行时缺模块）。

## 六、已知限制（不在本轮范围）

1. **站点级封锁无法绕过**：部分图源（如 bilimanga）对当前网络出口返回 Cloudflare 403/挑战页，需更换代理节点或由站点解除；应用侧已给出可读提示。
2. **无删除端点的收藏**：Bangumi 等不支持删除收藏，解绑仅清理本地记录，远端需手动移除。
3. **Win10 干净机矩阵**：宿主为异构大小核平台，Win10 22H2 客户机内核无法完成初始化（Win11 正常），该行测试标记为宿主平台限制。
4. **Trader 生产联调尚余服务**：MAL / Kitsu / Shikimori / MangaUpdates / Hikka / MangaBaka 与自托管 Komga / Kavita / Suwayomi 待提供凭证或实例后继续。
