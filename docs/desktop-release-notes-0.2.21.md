# 桌面版工作总结与发布说明（2026-09-26，v0.2.21）

本文件总结本轮 mihondesk 桌面端的修复与性能优化，作为 v0.2.21 发布说明与后续交接依据。

## 一、发布物

| 产物 | 说明 |
|---|---|
| `mihondesk-0.2.21.msi` | Windows 安装包（per-user，含开始菜单与快捷方式） |
| `mihondesk-0.2.21.exe` | Windows 安装器 |
| `mihondesk-0.2.21-windows-x64-portable.zip` | 便携版（解压即用，数据随包） |

发布包内容约定与 0.2.20 一致：不含任何图源扩展、用户配置、书架数据库、Cookie 或缓存；打包链 `verifyCleanDistribution` 与 `verifyRuntimeModules` 两道校验保持强制。

## 二、图源修复

1. **浏览报错不再显示裸异常类名**：扩展不支持「热门/最新」时（如 J-Novel），IPC 现在携带异常类型（`errorKind`），浏览页显示「该图源不支持浏览/最新，请使用搜索」的引导空态；热门/最新/搜索三条路径全覆盖，三语文案。
2. **vomic 等扩展的裸 `NullPointerException` 修复**：根因是扩展在 `headersBuilder()` 中依赖 Android 系统属性 `http.agent`（桌面 JVM 默认为 null）。扩展宿主启动时注入默认 UA 后恢复正常；同时裸异常的错误详情现在附带出错堆栈首帧（`NullPointerException at <类>.<方法>(文件:行)`），任何扩展报错都可定位。
3. **哔哩漫画等防盗链图源封面不显示修复**：封面请求此前不带图源请求头（Referer），被 403 拒绝后静默降级为占位符。现在所有封面调用点（浏览网格、全局搜索、图源迁移、书架、详情页、封面大图）自动附带 `Referer: <图源 baseUrl>`（baseUrl 缺失时用图片地址源站兜底）；403 纳入封面失败登记，不再静默。
4. **扩展包文件丢失自愈**：磁盘上的扩展包丢失但安装记录残留时（此前报 `No isolated host registered`），启动时自动清理脏记录并写回；打开受影响图源会得到「扩展文件丢失，请重新安装」的 actionable 提示。

## 三、性能优化（15 项）

- **偏好与扩展列表缓存**：`DesktopPreferenceStore` 增加文件戳（mtime+size）校验的快照缓存——每个 HTTP 请求、每条下载通知、每个图源状态不再全量读盘解析；跨实例与外部写入仍可被正确感知（单次 stat 代价）。已安装扩展列表 JSON 解码 memoize（22 个调用点受益）。
- **下载器持久化风暴消除**：下载进度不再每页全量读+解码+双写 `downloads.json`；改为合并落盘（约 500ms / 章节完成时），干净状态跳过备份重写，队列存储改紧凑 JSON；移除全器互斥锁；消除每页 O(pages²) 扫描与重复文件大小统计；启动时的已下载章节完整性扫描移出主线程，大下载库不再拖慢首帧。
- **IPC / 扩展运行时**：宿主最热路径每请求只解析一次 JSON（原两次）；扩展包加载消除重复的 zip 全量解压；`page-images` 临时文件纳入退出清扫；修复 IPC 超时错误被误当协程取消的正确性 bug（现在返回类型化超时错误）；收窄路由锁粒度；stderr 日志双写互相截断问题修复。
- **UI / 图片加载**：删除封面组件与加载器的双重重试（403 封面不再发 3 倍注定失败的请求）；封面请求头按图源 `remember` 缓存，恢复懒列表项的跳过重组能力；详情页封面不再因不稳定 lambda 反复取消重载；自定义封面探测加负缓存（书架滚动零磁盘 stat）；本地源书架快照每页只取一次。
- **设置页卡顿修复**：进入「备份与还原」不再在 UI 线程同步枚举网卡（VPN/TUN 适配器状态查询可堵数百毫秒）与生成配对二维码，两者均改异步，二维码区域预留尺寸不跳动。

## 四、测试与质量

- 新增/更新单测覆盖：UOE 浏览空态、IPC `errorKind` 传播、裸异常堆栈格式化、`http.agent` 注入、封面请求头生成、403 失败登记、缺失包 fail-fast、安装记录 reconcile、偏好缓存失效与跨实例可见性、下载存储合并落盘、自定义封面负缓存。
- 全量回归：`:desktop-app:test`（864 个测试，0 失败）、`:extension-host:test`、`:extension-sdk:test` 通过；三模块 `spotlessCheck` 通过。
- AppContainer 隔离测试在 MSIX/AppX 容器等无法嵌套沙箱的环境下改为跳过而非失败（正常 Windows 环境仍真实执行）；修复两个测试稳定性问题（下载器启动恢复竞态、Suwayomi 集成超时）。

## 六、已知限制（不在本轮范围）

1. 封面请求头当前只附带 Referer（baseUrl/图片源站）；需要完整扩展 headers（Cookie/UA 级）的个别图源仍可能加载失败，后续可考虑经 IPC 获取 `HttpSource.headers` 全量下发。
2. vomic 类扩展内部 bug 不可穷举；本版保证错误提示 actionable，扩展自身问题需上游修复。
3. 与 0.2.20 相同：书架同步不传播物理删除与下载文件。
