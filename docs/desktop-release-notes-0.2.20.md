# 桌面版工作总结与发布说明（2026-09-26，v0.2.20）

本文件总结本轮（mihondesk 桌面端 + Android 端）的功能交付，作为 v0.2.20 发布说明与后续交接依据。

## 一、发布物

| 产物 | 说明 |
|---|---|
| `mihondesk-0.2.20.msi` | Windows 安装包（per-user，含开始菜单与快捷方式） |
| `mihondesk-0.2.20.exe` | Windows 安装器 |
| `mihondesk-0.2.20-windows-x64-portable.zip` | 便携版（解压即用，数据随包） |

发布包内容约定与 0.2.19 一致：不含任何图源扩展、用户配置、书架数据库、Cookie 或缓存；打包链 `verifyCleanDistribution` 与 `verifyRuntimeModules` 两道校验保持强制。

## 二、核心功能：手机 ↔ 桌面书架同步（内置服务器通道）

此前版本（0.2.x 同步基建已入主干）依赖第三方文件同步工具搬运变更集。本版交付**开箱即用的内置同步通道**：

1. **桌面内置同步服务器**：设置 → 书架同步 → 开启"内置服务器"，桌面端即成为同步服务器（Ktor + SQLite，局域网 HTTP + token）。
2. **三种配对方式**：
   - **扫码配对**：桌面设置页显示配对二维码（与复制的配对码文本完全一致），手机"扫码配对"用相机扫码即完成；扫码界面带扫描框动画、无效码提示与手动输入兜底。
   - **局域网发现**：桌面通过 mDNS（`_mihonsync._tcp`）广播服务，手机"搜索局域网设备"自动列出附近设备；桌面开启"允许免输入配对"后点一下设备即完成配对（token 经 mDNS TXT 下发，**默认关闭**，开关带安全说明）。
   - **手动配对码**：`mihonsync://host:port#token` 粘贴输入，原路径保留兜底。
3. **同步内容**：收藏状态、章节已读、分类（含关联）、阅读进度，双向 LWW 合并（协议 baseSchema 1，与既有同步引擎一致，零协议改动）。
4. **安全口径**：局域网明文 + token 即凭证；"免输入配对"只应在可信网络开启；外部扫码器经 `mihonsync://` 链接打开 App 时需要用户在确认屏二次确认后才写入配对。

## 三、桌面端体验改进

- **关闭窗口后在后台运行**（新开关，默认关）：开启后点关闭按钮窗口隐藏到系统托盘，内置同步服务器保持运行（手机随时可同步）；托盘菜单提供"显示 / 退出"，首次入托盘有气泡提示。应用更新重启等程序化退出始终真退出，不受影响。
- **同步 IP 选择记忆**：多网卡/VPN 机器上选定同步 IP 后重启应用自动恢复上次选择；记忆的 IP 当前不可用时自动回退到可用列表第一项。配对二维码与配对码同源联动。

## 四、Android 端配套

- 设置 → 数据与存储 → 书架同步：配对码输入、扫码配对、搜索局域网设备、传输健康检查（测试连接）、同步频率/仅 Wi-Fi 选项。
- `mihonsync://` deep-link：外部扫码器扫码后点"打开链接"直达确认屏，确认后完成配对。

## 五、验证与质量

- 新增约 40 个单元测试全绿：配对码编解码、二维码生成/解码往返、JmDNS 广播发布/发现/TXT 断言（双实例真实多播）、NSD 解析纯函数（版本兼容/降级）、托盘后台运行决策、偏好 round-trip、同步 IP 选择回退。
- 全量回归：`:sync-server:test`、`:sync-transport-http:test`、`:desktop-app:test`（含新增）、`:app:testDebugUnitTest`（sync 包 25 项）通过；四模块 `spotlessCheck` 通过。
- 桌面 0.2.20 本机已实测安装并运行（MSI 全新安装，托盘/IP 记忆行为符合预期）。
- **待真机补验**（本版发布后由用户冒烟）：`docs/library-sync-smoke-test.md` 用例 0a–0d（扫码配对、外部 deep-link、发现+一键配对、AP 隔离降级）与用例 1–6（同步数据面），需要真手机 + 同一 Wi-Fi。

## 七、已知限制（不在本轮范围）

1. 同步通道为局域网直连：跨网络（不同 Wi-Fi/蜂窝）需后续独立服务器形态（计划见 `docs/library-sync-builtin-plan.md` Phase C）。
2. Android < 14 的 NSD 解析器可能不下发 TXT 记录 → 免输入一键配对降级为"预填地址"（设计上已兼容）。
3. 路由器 AP 隔离/访客网络会阻断 mDNS 发现 → 扫码/手动配对兜底。
4. 书架同步不传播物理删除与下载文件（与 0.2.x 同步语义一致）。
