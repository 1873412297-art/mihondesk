### 3.2 自动应答文件 `autounattend.xml`
- 文件路径: `H:\mihondesk-vm\win11-test\autounattend.xml`
- 关键配置：
  - `windowsPE` 阶段：
    - 自动 GPT 分区：300MB EFI 系统分区 (FAT32)、128MB MSR 分区、剩余空间为主分区 (C: 盘 NTFS)
    - 自动安装到 Disk 0 Partition 3，镜像索引：`/IMAGE/INDEX = 1`（匹配评估版单一镜像）
    - 自动接受 EULA 许可协议
    - `RunSynchronousCommand` 注入 `LabConfig` 虚拟化硬件免检项：`BypassTPMCheck=1`, `BypassSecureBootCheck=1`, `BypassRAMCheck=1`, `BypassCPUCheck=1`, `BypassStorageCheck=1`
  - `specialize` 阶段：
    - 计算机名：`win11-test`
    - 时区：`China Standard Time`
  - `oobeSystem` 阶段：
    - 区域语言：`zh-CN`
    - OOBE 页面全屏蔽：隐私设置拒绝 (`ProtectYourPC=3`)，跳过联机微软账户屏幕、EULA 屏幕、网络设置屏幕
    - 自动创建本地管理员账户：用户名 `testuser`，密码 `Test1234!`
    - 开启 AutoLogon (`testuser` 自动登录，次数 999)
    - `FirstLogonCommands` 自动配置 PowerShell 执行策略 `RemoteSigned`
