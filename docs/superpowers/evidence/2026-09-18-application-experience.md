## 实际变更

- 下载：持久化可分类的失败原因，兼容旧队列的原始错误；用中、英、繁体中文解释原因和恢复方法。原始诊断可展开、复制。新增搜索、带数量的状态筛选、清除筛选及批量重试失败。重试保留已成功页面；无匹配任务时不启动队列，暂停也覆盖等待项。
- 设置：下载路径先编辑再保存，在后台验证绝对路径、目录和写入权限。显示当前路径，解释重启生效及原有文件保留位置；保存不会覆盖同时修改的其他设置。
- 书架与历史：区分空书架和筛选无结果，提供清除筛选/搜索；卡片和列表中的图源兜底名称及章节计数跟随语言。保留共享详情页和现有桌面响应式布局。
- 浏览与全局搜索：取消过期查询，防止旧结果覆盖新搜索；离开搜索时取消任务，无图源时不持续加载。支持 Enter 搜索；网络错误给出可操作说明，失败后停止自动翻页请求。
- 阅读与更新：阅读错误面板限制宽度并支持滚动，诊断和恢复提示分开显示；保留取消、快捷键和深浅主题行为。更新失败显示本地化提示及独立诊断。
- Windows 通知：文案跟随实时语言设置，隐藏内容和禁用通知设置仍生效。逐页下载进度只更新应用内状态，不产生 Windows 弹窗；章节结果通知使用简明原因。
