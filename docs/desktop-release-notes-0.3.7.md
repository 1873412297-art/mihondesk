# 桌面版工作总结与发布说明（2026-10-13，v0.3.7）

本文件总结 v0.3.7 的交付内容。0.3.0–0.3.6 均为本地迭代版本，**从未发布、未打 tag**；其全部内容随本版一并发布（同版本号的 MSI 会被 Windows Installer 拒绝覆盖，因此版本号持续递增）。

## 一、发布物

| 产物 | 说明 |
|---|---|
| `mihondesk-0.3.7.msi` | Windows 安装包（per-user，含开始菜单与快捷方式） |
| `mihondesk-0.3.7.exe` | Windows 安装器 |
| `mihondesk-0.3.7-windows-x64-portable.zip` | 便携版（解压即用，数据随包） |

另附 `SHA256SUMS.txt`、`desktop-version.txt`、`mihon-build-info.properties`（由 `scripts/stage-release-upload.ps1` 生成，清单只列出随 Release 上传的文件）。发布包内容约定与 0.2.24 一致：不含任何图源扩展、用户配置、书架数据库、Cookie 或缓存。

## 二、界面与品牌（0.3.0–0.3.1）

- 统一品牌：暖纸色 + 赭墨（Ink）默认配色与新图标，经典蓝保留为可选主题；首次运行启动页 v3（尊重系统「减少动画」）。
- JBR 21 运行时 + 自定义标题栏（图标打开系统菜单，高对比度 / 高级设置回退系统标题栏）。
- 导航栏一致化（统计并入历史、关于并入设置）、可折叠导航栏（Ctrl+B）、界面密度设置、设置侧栏分组。
- 书架工具栏收纳到溢出菜单，Ctrl/Shift 多选取代常驻批量模式；阅读设置改为即时生效的侧面板。
- 可自定义键盘快捷键（含冲突检测）、Shift+点击范围选择、拖放导入、从书架卡片继续阅读、下载按漫画分组。

## 三、阅读器（0.3.2–0.3.3）

- 阅读器控件显示快捷键提示、缩放常驻高亮、沉浸模式下的缩放 HUD 与页码播报。
- 页面加载：延迟显示加载圈（命中缓存不闪烁）、慢加载后淡入、单页内联错误与「重试」。

## 四、浏览页重设计与扩展图标（0.3.4–0.3.6）

- 图源 / 扩展改为卡片行：48dp 图标、语言 / 18+ / 信任状态徽章；包名与图源 ID 收进提示与菜单；固定改为星标，「最新」为图标按钮，信任 / 停用 / 卸载收进溢出菜单；语言分组可折叠。
- **真实扩展图标**：安装时从 APK 的 `AndroidManifest` + `resources.arsc` 解析启动图标并取最高密度位图（兼容资源混淆与自适应图标）；已安装扩展启动后一次性补齐图标。
- **图标加载提速**：GitHub CDN 镜像回退（cdn / fastly / gcore jsDelivr 与 raw.githubusercontent.com），记住可用镜像、24 小时内跳过失败主机，短超时不重试，图标并发加载。
- 「系统代理」模式现在读取 Windows 系统代理，代理不可达时回退直连。

## 五、修复（0.3.7）

- 在任意文本框（如扩展 / 图源搜索框）中按 Backspace 或 Esc 不再触发「后退」：无修饰键的全局快捷键改在焦点控件处理之后执行，且文本输入期间一律不触发；Ctrl / Alt / F 键快捷键保持全局可用。新增回归测试。

## 六、验证

- 本机 `:desktop-app:test` 与 `spotlessCheck`：除 `SettingsScreenTest`、`DesktopLocalizationUiTest` 两项在 main 上即已存在的失败外全部通过。
- 本机 MSI 覆盖安装 0.3.6 → 0.3.7 成功，用户数据目录保留；扩展 / 图源搜索框内输入与删除不再离开浏览页，未聚焦文本框时 Backspace / Esc 后退正常。
- 发布前执行 `scripts/verify-release-clean.ps1`，发布后执行 `scripts/verify-release-assets.ps1 -Tag v0.3.7`。
